# GradeFlow frontend

This directory contains the React application for the GradeFlow prototype. See the [repository README](../README.md) for the project overview, current capabilities, setup instructions, limitations, and roadmap.

## Quick start

```bash
npm install
npm start
```

The app runs at http://localhost:3000. Use the instructor and student role selector to explore the two prototype views. The current experience uses sample data and is not connected to a production authentication or persistence service.

## Available scripts

- `npm start` — start the development server
- `npm test` — run the test suite
- `npm run build` — create a production build
